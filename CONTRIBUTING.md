# Contributing

Thanks for your interest in AL Additions.

## Bug reports

- Check existing issues first.
- Include browser and userscript manager versions.
- Describe the page, steps to reproduce, expected result, and actual result.
- Include relevant console errors with credentials and personal data removed.

## Feature requests

Explain the use case, where the feature should appear, and whether it should be optional in settings.

## Pull requests

- Keep changes focused and explain why they are needed.
- Test on the affected AniList and/or MyAnimeList pages.
- Avoid logging or exposing access tokens, authorization codes, or other secrets.
- Update the README or changelog when user-facing behaviour changes.
